What is integration?

Integration is the process of finding the area under a curve. Given a function f(x), its integral accumulates all the infinitely thin slices of area between the curve and the x-axis over an interval.

The Riemann Sum idea
Divide [a,b] into n thin rectangles of width Δx. Area of each = f(xᵢ)·Δx.
As n→∞ and Δx→0, the sum converges to the exact area: ∫ f(x) dx

The elongated S symbol ∫ comes from "Summa" (Latin for sum), introduced by Leibniz.

Antiderivatives and indefinite integrals

An antiderivative F(x) of f(x) is any function whose derivative is f(x): F′(x) = f(x). The indefinite integral collects all such functions:

Indefinite integral
∫ f(x) dx = F(x) + C
C is the constant of integration — any constant differentiates to zero.
  • Power rule: ∫ xn dx = xn+1/(n+1) + C  (n ≠ −1)
  • Constant rule: ∫ k dx = kx + C
  • Sum rule: ∫ [f+g] dx = ∫f dx + ∫g dx

1. Geometric meaning — Riemann sums

The mathematical problem that led to integral calculus was determining the area of plane surfaces bounded by curved boundaries.

Let y = f(x) be continuous on [a, b]. Divide the interval into n subintervals of width Δxᵢ and draw vertical lines to the curve. Within each subinterval build two rectangles:

  • Inscribed rectangle — height = minimum of f in the subinterval: f(xmᵢ). Located beneath the curve.
  • Circumscribed rectangle — height = maximum of f in the subinterval: f(xMᵢ). Located above the curve.
Key definitions
Curvilinear trapezoid: region bounded by x=a, x=b, y=f(x), and the x-axis.

Plurirectangle: union of all inscribed or circumscribed rectangles.
Area approximations
Sinscr = ∑ f(xmᵢ)·Δxᵢ  |  Scirc = ∑ f(xMᵢ)·Δxᵢ
True area S: Sinscr ≤ S ≤ Scirc
Taking the limit
As n→∞ (Δxᵢ→0), by the Squeeze Theorem both sums converge to: S = ∫ab f(x) dx
2. Sign of the definite integral
  • f(x) > 0 on [a,b]: integral is positive — ∫ab f(x)dx > 0
  • f(x) < 0 on [a,b]: integral is negative; geometric area = |∫ab f(x)dx|
  • f changes sign: split at c where f(c)=0 → S = ∫acf dx + ∫cbf dx
3. Fundamental Theorem of Calculus (Torricelli–Barrow)

Define the integral function S(t) = ∫at f(x)dx. Note: S(a)=0, S(b)=total area.

Theorem statement
S′(t) = f(t) — the derivative of the integral function equals the integrand at that point.
Proof sketch (from the teacher’s notes)
h·f(t) ≤ ΔS ≤ h·f(t+h) → divide by h → as h→0, Squeeze Theorem → S′(t)=f(t) ∎
Evaluation formula
S(a)=0 ⇒ C=−F(a) ⇒ ∫ab f(x)dx = F(b) − F(a)

Area between two curves

If f(x) ≥ g(x) on [a, b], the area of the region enclosed between the two curves is:

Formula (integrating with respect to x)
A = ∫ab [f(x) − g(x)] dx
Always subtract the lower curve from the upper curve to get a positive area.
  • Find intersection points by solving f(x) = g(x) — these become a and b.
  • Test a value inside the interval to confirm which function is on top.
  • If curves cross within [a,b], split the integral at each crossing point.
  • Can also integrate with respect to y: A = ∫ [right − left] dy
Example
Area between f(x)=x and g(x)=x²: intersections at x=0 and x=1.
On [0,1]: x ≥ x², so A = ∫01(x−x²)dx = [x²/2−x³/3]01 = 1/2−1/3 = 1/6

The disk method

When a region is rotated about an axis, thin disks (circular cross-sections) are stacked together. Each disk has radius r = f(x) and thickness dx.

Disk formula — rotation about the x-axis
V = π ∫ab [f(x)]² dx
Disk formula — rotation about the y-axis
V = π ∫cd [g(y)]² dy

The shell method

Instead of stacking disks, the shell method wraps thin cylindrical shells around the axis of rotation. Each shell has radius x, height f(x), thickness dx, and circumference 2πx.

Shell formula — rotation about the y-axis
V = 2π ∫ab x · f(x) dx
Shell formula — rotation about the x-axis
V = 2π ∫cd y · g(y) dy
  • The factor 2π comes from the circumference of the shell (2πr).
  • Shells are easier when the region is given as y=f(x) and rotation is about the y-axis.
  • When rotating about x=k (not the y-axis), the radius becomes |x−k|.
When to use shells vs disks
If the region is y=f(x) and you rotate about the y-axis: shells integrate in x (simpler). Disks would require expressing x = f⁻¹(y), which may be complicated.

Volumes with known cross-sectional areas

Not all solids are solids of revolution. When the cross-sectional area A(x) at each position x is known, the volume is:

General formula
V = ∫ab A(x) dx
A(x) = area of the cross-section perpendicular to the x-axis at position x.
This is the most general method — disks are just the special case where A(x)=πr².
Common cross-section shapes
  • Square with side s: A(x) = s²
  • Equilateral triangle with side s: A(x) = (√3/4)s²
  • Semicircle with diameter d: A(x) = πd²/8
  • Rectangle with base b and height h: A(x) = bh
Example — square cross sections
Base: y=√x, y=0 on [0,4]. Side s=√x → A(x)=x
V = ∫04 x dx = [x²/2]04 = 8
