SEZIONE 2 - Verifica AI Act: Conformità e Livello di Rischio (Reg. UE 2024/1689)

2.1 Controllo Pratiche Vietate (Articolo 5 AI Act)

  • • Riconoscimento Emozioni (Art. 5.1.f): Deduction/inferenza dello stato emotivo degli studenti dal codice o dai commit? ✓ NO (Conforme) SÌ (VIETATO)
  • • Tecniche Subliminali / Manipolazione (Art. 5.1.a): Tecniche ingannevoli per alterare il comportamento? ✓ NO (Conforme) SÌ (VIETATO)
  • • Punteggio Sociale / Social Scoring (Art. 5.1.c): Assegnazione di profili reputazionali o sociali sugli sviluppatori/studenti? ✓ NO (Conforme) SÌ (VIETATO)

2.2 Classificazione del Livello di Rischio e Obblighi Correlati

Alto Rischio (Art. 6 e Allegato III): Proctoring, esami automatizzati vinculanti o valutazione sommativa senza intervento umano?
✓ NO (Integrazione e supporto alla didattica/laboratorio di programmazione)
Obblighi di Trasparenza (Art. 50): Generazione automatica o autocompletamento di codice sorgente e commenti via IA?
✓ SÌ (Trasparenza + Obbligo di dichiarazione d'uso nei file o nei commit)
Sistema di IA Generativa (GPAI): Utilizzo di LLM/Codex per il completamento e la spiegazione di algoritmi?
✓ SÌ     NO
Supervisione Umana (Human Oversight): Revisione obbligatoria del docente e comprensione del codice da parte dello studente?
✓ SÌ (L'output è una proposta di codice soggetti a test, debug e validazione)

SEZIONE 3 - Conformità GDPR e Protezione Dati Personali (Reg. UE 2016/679)

Tipologia Dati Trattati ✓ Dati personali comuni: Username, email istituzionale, sorgenti di codice nei repository scolastici.
Dati particolari ex Art. 9 GDPR (Assolutamente vietati nei file di codice o nei prompt).
Gestione Prompt e Codice Sorgente ✓ SÌ — Divieto tassativo da regolamento interno di inserire dati identificativi, credenziali, API Key o dati sensibili nei repository o nei prompt inviati a Copilot.
Addestramento Modelli IA (Telemetry / Snippets) ✓ DISATTIVATO / NO — Nelle licenze GitHub Business/Education/Enterprise o tramite le impostazioni dell'organizzazione scolastica, l'opzione di trattenere gli snippet di codice per l'addestramento dei modelli pubblici è disattivabile/disattivata di default.
Account e Registrazione ✓ GitHub Classroom / Organizzazione Istituzionale Gestita con associazione ad email d'istituto (es. @scuola.edu.it) tramite GitHub Student Developer Pack.
Contratto e Garanzie Trasferimento (Art. 28 & 46) ✓ SÌ — Accordo sul Trattamento Dati (DPA Microsoft/GitHub) con Clausole Contrattuali Standard (SCC) ed adesione di Microsoft/GitHub all'EU-US Data Privacy Framework.

SEZIONE 6 - Esito della Valutazione e Proposta del Referente IA

✓ OPZIONE A - APPROVABILE PER USO GENERALE CON PRESCRIZIONI: Strumento idoneo per l'insegnamento dell'informatica, della programmazione e della gestione di progetti software, previo rispetto delle prescrizioni sulla protezione dei dati e sulla comprensione del codice.
Prescrizioni Operative Proposte:
  1. Dichiarazione d'Uso: Lo studente deve indicare nel commit o nei commenti del codice quali porzioni sono state generate tramite GitHub Copilot.
  2. Verifica delle Competenze: Il docente accerta sempre la capacità dello studente di spiegare e modificare il codice prodotto dall'IA.
  3. Divieto Dati Riservati: Vietato inserire password, API key, dati personali di studenti o verbali nei repository o nei prompt di Copilot.
  4. Configurazione Privacy: Verificare che l'organizzazione scolastica su GitHub disabiliti la condivisione degli snippet di codice con modelli pubblici.

SEZIONE 7 - Parere Formale del Responsabile Protezione Dati (DPO / RPD)

✓ PARERE FAVOREVOLE CON PRESCRIZIONI

Motivazione: L'infrastruttura GitHub / Microsoft garantisce elevati standard di sicurezza informatica (ISO 27001, DPF) ed offre una cornice contrattuale idonea (DPA con SCC). L'uso di GitHub Classroom e GitHub Copilot in ambito scolastico presenta un profilo di rischio contenuto per la privacy degli interessati, a condizione di operare all'interno dell'organizzazione d'istituto e di disattivare il tracciamento/riuso degli snippet per il training di modelli esterni.

Prescrizioni Vincolanti DPO:
  • Utilizzo esclusivo di account agganciati ad email istituzionali e gestiti nell'ambito di GitHub Classroom / GitHub Education.
  • Verifica ed attuazione dell'impostazione "Do not allow GitHub to use my code snippets for product improvements" nelle policy d'istituto.
  • Divieto assoluto di memorizzare dati personali, file con valutazioni o segreti tecnici nei repository pubblici o privati.
