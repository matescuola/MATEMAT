SEZIONE 3 - Conformità GDPR e Protezione Dati Personali (Reg. UE 2016/679)

Tipologia Dati Trattati ✓ Modalità Anonima (PIN): Nessun dato personale memorizzato per gli studenti.
✓ Modalità Registrata: Dati comuni (Email istituzionale docente/studente, nome/nickname).
Dati particolari ex Art. 9 GDPR (Assenti nei quiz e vietati nei prompt).
Gestione Prompt e Input IA ✓ SÌ — Divieto da regolamento interno di inserire dati identificativi o personali di studenti nei documenti allegati o nei prompt inviati a Panquiz AI.
Addestramento Modelli IA ✓ NO — Panquiz utilizza API aziendali riservate che NON utilizzano i testi, i prompt o i documenti inviati per addestrare modelli di IA pubblici.
Account e Accesso Minori ✓ Accesso tramite PIN/QR (senza registrazione) oppure Single Sign-On Istituzionale (Google/Microsoft 365).
Contratto e Nomina Art. 28 ✓ SÌ — Data Processing Agreement (DPA) sottoscrivibile / conforme alla normativa vigente.

SEZIONE 6 - Esito della Valutazione e Proposta del Referente IA

✓ OPZIONE A - APPROVABILE PER USO GENERALE: Strumento a rischio minimo/nullo, privo di impatto sulla privacy se utilizzato con codici PIN o account gestiti e sotto la costante supervisione del docente.
Prescrizioni Operative Proposte:
  1. Verifica dell'Output: Il docente è tenuto a revisionare integralmente le domande generate dall'IA prima della somministrazione.
  2. Minimizzazione Dati: Privilegiare la modalità di accesso via PIN/QR Code per gli studenti senza registrazione di dati personali.
  3. Divieto Dati Riservati: Non inserire verbali, valutazioni personali o dati di studenti con BES/DSA nei prompt di generazione test.
  4. Trasparenza: Segnalare agli studenti quando un test o quiz è stato generato con il supporto di Panquiz AI.

SEZIONE 7 - Parere Formale del Responsabile Protezione Dati (DPO / RPD)

✓ PARERE FAVOREVOLE CON PRESCRIZIONI

Motivazione: Lo strumento Panquiz presenta eccellenti garanzie di conformità, essendo fornito da sviluppatore italiano/UE e consentendo la fruizione dei quiz tramite modalità completamente anonima (PIN/QR Code). Le API IA utilizzate disabilitano il riuso dei dati scolastici per l'addestramento di modelli pubblici. Il rischio per i diritti e le libertà degli interessati è classificabile come minimo.

Prescrizioni Vincolanti DPO:
  • Fruizione preferenziale per gli studenti tramite sessione anonima (PIN di gioco/test) senza creazione di account personali non gestiti.
  • Assoluto divieto di inserire dati identificativi o sensibili degli alunni nei testi allegati a Panquiz AI.
  • Perfezionamento del DPA ex Art. 28 GDPR con il fornitore in caso di utilizzo di account nominali.
