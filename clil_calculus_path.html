What does differentiable mean?

A function f(x) is differentiable at a point x = a if the following limit exists:

Definition
limh→0 [f(a+h) − f(a)] / h

This limit must exist and must be the same from both the left and the right side.

Visually: as you zoom in on the graph at that point, the curve must look like a straight line. If it stays "pointy" (corner or cusp), the derivative does not exist.

When is a function NOT differentiable?
  • Sharp corner / cusp — e.g. f(x) = |x| at x = 0: left limit = −1, right limit = +1. They differ, so no derivative exists.
  • Vertical tangent — e.g. f(x) = x1/3 at x = 0: derivative → ∞.
  • Discontinuity — e.g. the floor function at integer values: a jump means no derivative.
  • Infinite oscillation — e.g. sin(1/x) near x = 0: the slope never settles.
Key implication
Differentiable ⟹ Continuous  |  But: Continuous ≠ Differentiable

Critical (stationary) points

A stationary point occurs where f′(x) = 0. At these points the tangent line is horizontal — the function momentarily flattens out.

Second derivative test
Find x where f′(x) = 0, then compute f″(x):

• f″(x) < 0 → local maximum (concave downward at that point)
• f″(x) > 0 → local minimum (concave upward at that point)
• f″(x) = 0 → test is inconclusive (may be a saddle/inflection point)
Intervals of monotonicity

The sign of f′(x) tells us whether the function is increasing or decreasing:

  • f′(x) > 0 on an interval → f is increasing on that interval.
  • f′(x) < 0 on an interval → f is decreasing on that interval.
  • The transition points (where f′ = 0 and the sign changes) are the local extrema.
Real-world example
A ball thrown upward: h(t) = 3 + 14t − 5t²
h′(t) = 14 − 10t = 0 → t = 1.4 s (maximum height)
h′ > 0 for t < 1.4 (rising)  |  h′ < 0 for t > 1.4 (falling)

Concave upward and concave downward

Concavity describes how the slope is changing:

Rules
• f″(x) > 0 → curve is concave upward (∪ shape — like a cup)
 the slope is increasing

• f″(x) < 0 → curve is concave downward (∩ shape — like a cap)
 the slope is decreasing
Memory trick
CUP = Concave Up → the shape holds water like a cup ∪
Inflection points

An inflection point is where the curve switches from concave upward to concave downward (or vice versa). The second derivative changes sign there.

  • Set f″(x) = 0 and check that the sign of f″ actually changes around that point.
  • Warning: f″(x₀) = 0 is necessary but NOT sufficient. The sign must change.
  • Example: for y = x⁴, f″(0) = 0 but f″ > 0 on both sides → no inflection point.
