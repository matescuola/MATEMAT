I Teoremi di Euclide
sul Triangolo Rettangolo

Guida interattiva — passo dopo passo

Problema.
In un triangolo rettangolo ABC (retto in C) i cateti misurano a = BC = 3 cm e b = AC = 4 cm.
Trova: l'ipotenusa c, le proiezioni dei cateti sull'ipotenusa (p e q) e l'altezza h relativa all'ipotenusa.

[c = 5 · p = 9/5 · q = 16/5 · h = 12/5]
Passo 1 di 6
1
Capire la figura
Identificare tutti gli elementi
Nel triangolo rettangolo ABC retto in C, chiamiamo H il piede dell'altezza condotta da C sull'ipotenusa AB.

Gli elementi chiave sono:
• a = BC = 3 cm · b = AC = 4 cm · c = AB = ipotenusa
• p = AH = proiezione di b (cateto AC) sull'ipotenusa
• q = HB = proiezione di a (cateto BC) sull'ipotenusa
• h = CH = altezza relativa all'ipotenusa
💡 Rifletti

Quanti triangoli rettangoli vedi nella figura, contando anche quello grande?

2
Prima cosa: l'ipotenusa
Teorema di Pitagora
Prima di applicare Euclide, calcoliamo l'ipotenusa c con il teorema di Pitagora:
c² = a² + b² = 9 + 16 = 25 → c = 5 cmipotenusa del triangolo 3-4-5
Notiamo subito che 3-4-5 è il triplo pitagorico fondamentale. Ora siamo pronti per applicare i teoremi di Euclide.
✏️ Verifica

Quale relazione lega p, q e c (le due proiezioni e l'ipotenusa)?

3
Primo Teorema di Euclide
Cateto² = ipotenusa × proiezione del cateto
📐 1° Teorema di Euclide
Il primo teorema di Euclide afferma che ogni cateto è medio proporzionale tra l'ipotenusa e la proiezione di quel cateto sull'ipotenusa:
per il cateto b = AC b² = c · p p = proiezione di b
per il cateto a = BC a² = c · q q = proiezione di a
Sostituiamo i valori noti (a = 3, b = 4, c = 5):
p = b²/c = 16/5 = 3,2 cm
q = a²/c = 9/5 = 1,8 cm verifica: p + q = 3,2 + 1,8 = 5 = c ✓
🧮 Calcola

Usa il 1° teorema di Euclide: quanto vale p = AH (proiezione di AC)?

p = cm
p = b²/c = 4²/5 = 16/5 = 3,2 cm
4
La seconda proiezione
Trovare q = HB
📐 1° Teorema di Euclide
Possiamo trovare q in due modi:
Modo 1: q = a²/c = 9/5 = 1,8 cm
Modo 2: q = c − p = 5 − 3,2 = 1,8 cm entrambi danno lo stesso risultato ✓
💡 Rifletti

Il cateto più lungo (b=4) ha la proiezione più lunga o più corta sull'ipotenusa?

5
Secondo Teorema di Euclide
Altezza² = prodotto delle proiezioni
✨ 2° Teorema di Euclide
Il secondo teorema di Euclide afferma che l'altezza relativa all'ipotenusa è il medio proporzionale tra le due proiezioni:
2° Teorema di Euclide h² = p · q altezza = medio proporzionale tra p e q
Formula equivalente h = a·b / c prodotto dei cateti / ipotenusa
Possiamo usare entrambe le formule per verificare il risultato.
🧮 Calcola h

Usa il 2° teorema di Euclide: h² = p · q. Quanto vale h?

h = cm
h² = p · q = 3,2 × 1,8 = 5,76
h = √5,76 = 2,4 cm

Verifica con l'altra formula:
h = a·b/c = 3×4/5 = 12/5 = 2,4 cm ✓
6
Schema risolutivo completo
Tutti i teoremi applicati in sintesi
① Pitagora
c = √(a²+b²) = √(9+16) = 5 cm
② 1° Teorema di Euclide
p = b²/c = 16/5 = 3,2 cm  ·  q = a²/c = 9/5 = 1,8 cm
verifica: p+q = 5 = c ✓
③ 2° Teorema di Euclide
h = √(p·q) = √(3,2×1,8) = √5,76 = 2,4 cm
verifica: h = a·b/c = 12/5 = 2,4 ✓
